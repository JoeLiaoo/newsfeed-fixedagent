# P2 首个专家：新华财经适配说明

首个目录项参考 [`reference/SKILL.md`](../reference/SKILL.md) 的“单体分析09-对外投资全景图核查”。原技能要求悟道 MCP，并依赖 10/11/12 专项 skill；这些依赖当前未接入。本站适配版使用新华财经 `zjs_company` MCP 和 DeepSeek，任务页及产物均标记为**试运行底稿**。

| 原技能规则／能力 | 状态 | 当前适配与边界 |
|---|---|---|
| 实体检索并先锚定 ID | 支持（人工确认） | `fuzzy_search_company_list` 返回候选；员工必须选择匹配主体后才继续。 |
| 主体工商画像 | 部分支持 | 读取 `get_company_profile` 返回的可用画像字段；缺字段显示“未提供”。 |
| 直接投资记录、比例与认缴原始字段 | 部分支持 | `get_direct_investment` 输出一层关系清单；数值和日期保留服务商原始文本，不做单位换算或日期语义推断。 |
| 按控股／参股逐层穿透 | 缺失 | 目前不会递归查询，也不声称全量覆盖集团链条。 |
| 关联方合并计算控制权、第一大股东判断 | 缺失 | 未接入关联方关系证据和控制权规则引擎。 |
| 非上市参股终止、投资类主体例外及继续穿透 | 缺失 | 不按名称或比例推断停止／续钻。 |
| 上市公司终止及代码标注 | 缺失 | 当前工具适配未实现上市主体判定。 |
| 合伙基金备案、公司制基金识别及组合披露终止 | 缺失 | 未接入基金备案工具；不能把无返回字段当作未备案。 |
| GP、执行事务合伙人、管理人及备案信息 | 缺失 | 不执行原技能的角色提取规则。 |
| 状态交叉核验、注销数据清零判断 | 部分支持 | 可展示主体画像返回的登记状态；不做年报多年度交叉验证或状态终裁。 |
| 历史退出、承接方和六类退出性质 | 缺失 | 当前不查询历史投资，不输出退出性质。 |
| 三类主体专门附件及附表完整性守卫 | 缺失 | 悟道与 10/11/12 专项 skill 均未接入。 |
| 事实引用、无数据时保留缺口 | 支持（有限范围） | 一层记录附 `S1...` 证据编号、字段原值和新华财经工具名；缺字段标为未提供。DeepSeek 仅整理摘要和待核问题，不能补造工商字段。 |

页面示例输入为“上海天之际创业投资合伙企业（有限合伙）”和“杭州市国有资本投资运营有限公司”。示例只用于员工提交查询；没有在本次开发中调用外部 MCP 或预先生成企业数据。

## 运行边界

- 用户上传的 SKILL.md 或 ZIP 只作为文本保存和展示，不执行脚本、模板、网页或包内程序。ZIP 根目录仅允许 `manifest.json` 与 `SKILL.md`；限制压缩体积、条目数量、解压声明大小及路径。
- 导入文件缺少的 skill/MCP 依赖会记录并阻止运行。自定义专家只使用 DeepSeek 文本生成，不向用户包开放 MCP、代码执行或文件系统权限。
- MCP 工具采用服务端固定 allowlist，token 从 `XINHUA_MCP_API_KEY` 凭据组读取；远端地址固定在 `mcp.cnfic.com.cn` 的 HTTPS 主机范围。
- 员工材料目前是受长度限制的纯文本备注，不支持任意文件上传。任务文本、结果和产物隔离到所属用户；任务和产物均于创建后 7 天清理。
- 真实新华财经账号、工具 schema 和 DeepSeek 实际配置仍需部署后端到端试用。试运行底稿不能替代正式尽调复核。
