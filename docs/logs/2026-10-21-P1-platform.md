## 关键决定及边界

- 网站文章列表使用 AIHOT 的 `web_list`；对全站 sitemap 提交增加 `sitemap` 解析，并将每轮最多处理的 sitemap 文件数及文章 URL 数设为上限。sitemap 的 `lastmod` 不当作真实发布日期。站点覆盖仍取决于来源本身是否公开、索引是否完整及采集器解析结果。
- 员工信源提交后进入全员共享池；系统不采集登录或付费内容。个人日报只查询 `publications` 的公开、合格内容，不绕过撤回和发布边界。
- 专家页目前是导航占位页；专家导入和异步任务属于 P2，未在此声称已实现。新华财经 MCP 与 GP 事件同属后续阶段。

## 部署/试用步骤

1. `cp .env.example .env`，设置数据库密码、`SESSION_SECRET`、`IMG_PROXY_SIGN_SECRET` 和 DeepSeek 配置。
2. `docker compose up -d --build`，等待 `setup` 成功。
3. 在 `.env` 设置首位管理员的用户名、真实姓名和密码，执行 `docker compose up -d api` 让容器读取一次性变量，再执行 `docker compose exec api npm run member:bootstrap-admin`，随后删除临时变量并重启 API。
4. 分别注册两个员工账号，经管理员审核后分别选择不同的赛道；在已有公开精选内容或经检查添加 RSS/sitemap 后确认首页条目与兴趣匹配、来源可打开。
5. 核对待审核、账号状态、提交信源状态及两个账号分别看到的日报。记录来源抓取失败和标签误分，再决定是否可进入下一阶段。
