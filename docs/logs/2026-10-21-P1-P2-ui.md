# P1/P2 前端组件整改

日期：2026-10-21
范围：P1 账号与资讯页面、P2 专家执行页面

## 完成内容

- 在 `apps/web/app/components/member-ui/` 建立源码可控、共用站点语义色和间距变量的组件源：Button、Input、Textarea、Label、Checkbox、RadioGroup、Card、Badge 和 Alert。来源类型继续使用有原生键盘和屏幕阅读器支持的 HTML `select`。
- 交互复用 Radix Checkbox 与 RadioGroup，按钮变体使用 class-variance-authority，类名合并使用 clsx 与 tailwind-merge，界面图标统一使用 Lucide。页面没有引入新的动画、拖拽或分栏状态库；相关交互不需要这些能力，Motion 仍沿用现有依赖。
- P1 登录、注册、关注赛道、员工账号审核、资讯信源页面统一使用共享组件；赛道复选框和专家选项提供键盘及辅助技术语义。
- P2 专家目录、任务表单、技能导入、主体选择、任务状态和产物操作统一使用共享组件。
- 注册、登录、关注保存、新增标签、信源检查和专家任务操作补充请求异常状态；保留原有 API 契约与业务规则。
- 更新 `AGENTS.md` 的组件与依赖规范，并在实施进度页记录整改。

## 关键决策

- 以 shadcn/ui 源码可控的组件管理方式组织共享组件，并复用现有主题变量，避免在会员页面引入另一套页面 token 或全站 CSS 重置。
- 不为本次页面增加 Zustand、Motion、dnd-kit 或可调整分栏；页面没有复杂共享状态、动效、拖放或可调布局需求。
- P1/P2 页面使用同一套共享组件；既有资讯与内容组件未纳入本次外观迁移范围。
