## 修复内容

- 将新迁移移至 `0090–0100`，每个文件一条迁移语句。管理员会话约束先添加并验证扩展后的允许值，再移除旧约束；会员账户、会话、关注标签、公共标签和日报快照各自独立建表，索引使用 `CREATE INDEX CONCURRENTLY`。

- 日报按用户、北京时间日期和关注版本存储首个成功快照，窗口从上一期成功截止点到本期固定截止点；按 story、fact 或 article 去重，保存当期关注标签和条目，提供历史记录及按日期读取。偏好未变化时重复保存不会增加版本；新增公共标签会原子写入创建者的个人关注。
- 首页添加日报历史导航，显示统计窗口和偏好版本。
- 首页来源申请探测页面 RSS、robots.txt 与常见 sitemap 地址，优先选择 sitemap，其次 RSS；未发现时回退到提交的文章列表。将实际范围、发现方式和首次预览数量写入来源配置，并在来源页持续显示这些值和近 7 天收录量。预览限制为每用户每小时 3 次、单用户单并发和 API 进程最多 4 个并发；网站列表回退每次最多抓取 5 篇详情，sitemap 预览最多抓取 15 篇详情。`docs/PLAN.md` v0.65 将未发现 sitemap/feed 时的列表页范围列为明确的首版验收边界。
- 新增一个会员 API 契约测试，覆盖匿名拒绝、私有缓存/CORS、双账号关注隔离、自定义标签持久化、跨来源同事件去重、日报快照稳定性和历史记录。
