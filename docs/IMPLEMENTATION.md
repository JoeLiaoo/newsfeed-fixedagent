## 执行规则

- 按依赖逐项推进。每个完成任务必须有 `docs/logs/` 中的日志，并在下表勾选及填写日志链接；阻碍和部分完成只记日志，不勾选。
- 验证以当前变更所需的最小检查为限。不要运行全量测试；用户负责真实账号、个人微信和业务效果的最终试用。未验证项在日志中列明。
- 不把供应商返回的入库时间直接作为投资事件日期，不让模型补造融资事实。功能缺失时清楚展示，不假报完成。
- 状态 `—（转入其他任务）` 表示按用户决定不再单独执行，相关产品验收并入指定任务；不表示已完成。
- 旧版本曾归档，后按用户授权退役；新平台自身的备份恢复仍属于 P4 运维验收。任务勾选不授权额外清理服务器。
- PR 合并、Issue 关闭、CI 通过、生产部署和真实业务验收分别记录；任一状态不能替代其他状态。按 2026-10-25 用户复测信息，生产当前为 `5594d1d`（含 PR #70／#72／#73）；本仓库没有这次发布的独立运维日志，不能据此认定专家或 GP 业务已验收。

本轮赛道同业检索分支基于 `origin/main` 的 `036cb10`。生产版本由用户说明；本分支不连接生产实例。以下勾选只按各行完成标准，不随合并或部署自动变化。
