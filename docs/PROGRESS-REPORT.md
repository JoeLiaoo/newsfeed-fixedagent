## 已到达的位置

- 网站账号、兴趣订阅、公开资讯、个人日报和专家任务已形成可试用的代码链路；P1、P2 的任务勾选表示相应开发标准已满足，不代表所有员工场景和专家产物已验收。
- 新平台已部署到 `ai-work`，HTTPS 健康检查与登录页可访问；管理员登录已由用户确认。DeepSeek 与新华财经完成过单次隔离连通抽测，持续稳定性及业务结果仍待验证。
- Hermes Weixin/iLink 已部署为独立 systemd 网关，单个 bot 身份扫码连接成功；私聊使用配对审批、群聊关闭。该网关尚未接入网页平台 bridge，也未完成两名员工的分别投递及跨日试用。
- GP 管线与通知 outbox 的基础代码已合并，P3 的四项验收仍为未完成；`P3_GP_SYNC_ENABLED`、`P3_NOTIFICATIONS_ENABLED`、`P3_DELIVERY_ENABLED` 应保持关闭，直到真实渠道和业务数据验收。

## 下一步验收关口

1. **员工与资讯：**两个账号完成审核，选择不同细分赛道，核对各自日报、资讯隔离和新增信源覆盖。
2. **专家与数据源：**用业务样例核对新华财经查询、DeepSeek 分类和报告的来源、缺失字段及一层直接投资限制。
3. **GP 与微信：**管理员核对 GP 主体及投资证据；打通 Hermes 网页绑定，并由两名用户连续跨日验证定向消息。
4. **正式运维：**完成新平台的实例外备份与恢复、监控和费用记录、回退步骤及员工试运行结论；核实旧组件退役范围和共享资源影响。

任务的唯一勾选来源是 [实施计划](IMPLEMENTATION.md)。若其状态变化，更新本报告的日期、计数和文字；不要仅因代码合并或网页可访问而增加勾选数。
