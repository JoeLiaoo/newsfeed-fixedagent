## 已到达的位置

- 网站账号、兴趣订阅、公开资讯、个人日报和专家任务已形成可试用的代码链路；P1、P2 的任务勾选表示相应开发标准已满足，不代表所有员工场景和专家产物已验收。
- 新平台已部署到 `ai-work`，HTTPS 健康检查与登录页可访问；管理员登录已由用户确认。已记录的最新生产发布是 [PR #38 卡片界面发布](logs/2026-10-24-P4-pr38-cards-deployment.md)（release `d81f901`，2026-10-24），其中已包含 PR #38 的专家与知识库卡片列表；PR #32～#34 已合并并随 `4a91199` 发布上线，真实业务验收仍未完成。DeepSeek 与新华财经完成过单次隔离真实调用；新华财经取得候选、画像和 13 条一层直接投资记录，持续稳定性及完整业务结果仍待验证。
- 旧应用与旧 Workbench 组件已在同机退役（Compose 项目、旧 systemd 单元、旧发布树、旧数据库与旧归档），新平台、Hermes 网关、系统 Nginx 与 IP 证书续期链路保持运行，见[旧组件退役记录](logs/2026-10-24-P4-02-old-component-retire.md)。退役后公网健康检查仍返回 `ok=true`、`db=ok`。
- Hermes Weixin/iLink 独立网关与网页绑定 bridge 已运行。两名员工账号已绑定；各自的连通性测试通知已通过生产 outbox 投递，均获 iLink `accepted` 回执，用户确认两台手机均已收到。跨日投递与窗口失效恢复尚未验证。
- PR #22（release `8a84319`）已部署个人微信二维码新标签页、扫码结果提示和消息状态框。生产四项 P3 开关按用户指示启用；普通 Hermes 聊天仍单独审批。
- GP 同步的目标、数据证据与实际产出尚未核验；测试消息不代表日报生成链路或业务投递验收完成。P3-01～P3-04 均保持未完成。
- 全公司共享投研知识库的代码链路已完成（上传、自动构建、复核、发布、浏览检索、问答与引用、撤回），PR #34 的 CI 与临时 PostgreSQL 场景检查通过，生产迁移已随 2026-10-24 的发布应用；真实账号与真实材料仍待验证，P5-02～P5-04 保持未完成。
- 专家平台与知识库已改为对称的卡片入口（列表 → 详情再操作，页头分别「+ 新增专家」与「+ 新增知识库」），知识库按库组织并保留一个默认共享库；见 [Issue #36 工作日志](logs/2026-10-24-i36-expert-knowledge-cards.md)。该改动已在 PR #38 合并（`78c0fa3`），并随 2026-10-24 的 `d81f901` 发布上线，生产迁移（`0176`–`0180`）已应用；真实员工验收仍未开始。
