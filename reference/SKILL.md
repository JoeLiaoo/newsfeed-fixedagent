# 09 · 对外投资全景图核查

产出：`extract/对外投资全景底稿.md`（分层表 + SPV架构 + 全景汇总）+ 中间文件 `_inv_<子公司>.jsonl`（穿透原始数据，断点续跑用）。

本 skill 是单体报告第一章架构图与第三章投资四分法的**供数前置**：目标是把体系内每个主体的对外出资全量、逐层、带链条地提取出来，不允许"查一层就放"。

## 1. 数据源与工具（硬约束）

**只用悟道MCP**（wudao_mcp_gateway）。企查查看积分需用户同意才用；天眼查已停用。披露文件（募集书/审计附注）仅作名单比对与差异说明，不作穿透主源。

| 用途 | 服务·工具 | 关键返回字段 |
|---|---|---|
| 实体锚定（名称→ID） | 实体查找·`search_enterprises` | comp_id_iwudao、状态、注册资本、法人 |
| 对外投资全量（向下钻取主工具） | 工商基础信息·`get_external_investments_by_id` | param=shareholder_id（股东ID）；被投主体、stock_proportion、pays.capital（认缴）、入股日期 |
| GP/执行事务合伙人提取 | 工商基础信息·`get_company_basic_info_by_id`（主）+`get_shareholders_by_id`（复核） | legal_person_name（有限合伙"法人"字段即执行事务合伙人）+legal_person_type（1=企业GP、2=自然人GP）；股东名单复核GP位置及比例 |
| 主体基本情况 | 工商基础信息·`get_company_basic_info_by_id` | 成立日期、注册资本、状态、经营范围（SPV判断依据） |
| 历史出资（退出） | 工商基础信息·`get_historical_external_investments_by_id` | 含remove_date的退出记录 |
| 基金备案（管理人/备案状态） | 基金·`get_fund_basic_info` | fund_manager_name、备案日期、运作状态、组织形式 |

**调用纪律**：
- 一切查询先过 `search_enterprises` 拿到 comp_id_iwudao，**禁止拿名称直接猜ID**；同名多候选时以注册资本/成立日期/地区与披露文件比对锁定，并记录锁定依据。
- `get_external_investments_by_id`/`get_historical_external_investments_by_id` 的必填参数为 **shareholder_id（股东ID）**——悟道公司 comp_id 与人员 person_id 共用同一编号空间，查询主体的 comp_id 直接作股东ID传入；认缴额取返回记录 pays 字典的 **capital 字段**。
- 查询结果**追加写入** `_inv_<一级子公司名>.jsonl`（每行一条JSON，含查询主体ID、工具、原始返回），中断后可读文件续跑，不重复扣调用。
- 以 comp_id 去重，同一主体全谱系只穿透一次。
- 工具返回 status_code=-2/2/-1 按提示间隔重试，勿静默丢弃。
- **ID碰撞噪音过滤（硬约束，2026-10-11强化）**：悟道 comp_id 与 person_id 共用编号空间，`get_external_investments_by_id`/`get_historical_external_investments_by_id` 返回可能混入无关主体出资（股东名混入自然人姓名）。每条记录须按 shareholder_name ∈ {查询主体名、曾用名} 过滤，入股日期早于被查询主体成立日期的记录剔除；滤出噪音单列"噪音待核"，不得入表。**存在性核查纪律（历史出资同样适用）**：工商实体存在 ≠ 投资关系存在，可疑记录须逐笔复核——噪音三特征：①入股日期早于投资方成立日期；②comp_id 与相邻主体相邻且入股/退出日期完全一致（影子记录）；③pays/持股比例/证件号全 null（裸记录）。命中即剔除，主体名只出现于"噪音已剔除"注记（附剔除依据），**不得以任何形式出现在表行**。

## 2. 穿透核查规则（核心，逐字执行）

**三条终止条件（先行判断，无论持股比例，一律即止）**：
1. **上市公司即止**（规则5）：T 为沪深北/港股/美股上市公司 → 停止下钻；
2. **备案基金即止**（规则3）：T 为已备案私募基金（有限合伙形式）→ 停止下钻，不披露基金对外投资组合；
3. **公司制基金即止**（规则6）：T 为公司制基金（有限公司/股份公司形式基金）→ 视同备案基金即止。

设当前核查主体为 S（S 的对外投资来自 `get_external_investments_by_id`），对其每个被投对象 T 按序判断：

**控股/参股判定口径（先于各规则，关联方合并）**：不能只看 S 单一主体持股比例，须把**关联方持股合并计算**（同受目标集团控制、或披露文件认定的关联方，各自对 T 的持股加总）：
- 合并持股 **≥50%** → 控股；
- 合并持股 **<50% 但为 T 第一大股东**（合并口径）→ **参考控股**，按规则2续钻；
- 合并持股 <50% 且非第一大股东，且无章程/协议控制证据 → 参股，按规则1即止。
- 合并计算过程入底稿（哪些关联方各持多少、合计多少、是否第一大股东），表内标注"合并口径XX%【第一大股东】"或"合并口径XX%"。
- 范例：杭州产业投资旗下杭州吉海信息科技有限公司——产业投资36.4771%+杭州市产业发展投资13.5229%=**合并50.0000%→控股**，按规则2续钻（杭州市产业发展投资穿透为金投系·市财政局、非杭州资本体系内，按合并口径认定并注记供判断）。

**规则1·参股即止**：T 为**非上市公司**且按上述口径为**参股** → T 即披露尽头，停止下钻，标注【参股·尽头】。

**规则2·控股续钻（含两个例外）**：T 为非上市公司且为**控股（含参考控股）** → 对 T 执行同样的对外投资核查，逐层往下，**直至无控股/参考控股子公司，或撞到参股尽头/三条终止条件**。每层入表不得跳层；参考控股层标注【参考控股·合并第一大股东】。
- **例外1·投资类主体续钻**：T 为**投资、管理或咨询字样**的主体（经营范围/主营亦为投资类），**即便参股也往下核查**——其对外投资涉有限合伙→按规则3穿透；涉公司且该公司仍是投资/管理/咨询字样、主营投资→**不管控股参股继续逐层下钻**；**直至出到已备案基金产品（即止），或未备案有限合伙往下出到公司标的（即止）**。判断依据写清（名称+经营范围原文摘录），链条每层标注【SPV】。
- **例外2·投资平台铁律**：T 为**集成电路等产业投资平台**——出资方式为有限责任公司、经营范围主要写投资（如"股权投资、实业投资、投资咨询"），即便参股也续钻，**最终出资到国家集成电路产业投资基金（大基金）即止**（公司制基金，按终止条件3即止）。范例：杭州钱塘集成电路产业发展有限公司（产业投资50%）→ 浙江富浙集成电路产业发展有限公司（参股20%）→ 国家集成电路产业投资基金二期股份有限公司7.3475%【公司制基金·即止】。

**规则3·有限合伙份额链（备案基金即止）**：S 的出资对象是**有限合伙企业份额** → 先判 T 是否**已备案私募基金**：
- T **已备案** → 链条止于 T，不穿透其对外投资，标注【备案基金·即止】，按规则4提取执行事务合伙人+基金管理人+备案信息；基金对外投资组合不披露（私募基金组合非公开且动态变化）。
- **备案判定口径（2026-10-10修订）**：MCP 企业标识（企业标签）含**"私募基金"标签 = 已备案**；**无该标签 = 未备案**。需严格核查的，上中国证券投资基金业协会信息公示核查：https://gs.amac.org.cn/amac-infodisc/res/pof/fund/index.html
- T **未备案** → 穿透 T 的对外投资：投到**公司**（不管控股参股）→ 该公司即链条终点，不再下钻；投到的仍是**有限合伙份额** → 继续穿透，直至"出到公司"为止。
- 整条份额链每层入表，链条首尾关系必须可追溯；**仅经由备案基金路径**的未备案有限合伙及出到公司主体随链抑制（其披露路径唯一经基金，不再展示）。

**规则4·有限合伙双提取**：凡有限合伙：
- **必提取执行事务合伙人**——取 `get_company_basic_info_by_id`（param=comp_id_iwudao）返回的 legal_person_name（有限合伙的"法人"字段即执行事务合伙人）与 legal_person_type（**1=企业、即企业GP；2=自然人、即自然人GP**），并用 `get_shareholders_by_id` 复核其在合伙人名单中的位置及比例；
- 若该有限合伙为**已备案私募基金** → 还须提取**基金管理人**（fund_manager_name+登记编号）、备案日期、运作状态；管理人与执行事务合伙人**可能是两个主体，都要列**。

**规则5·上市公司即止**：T 为**上市公司**（沪深北A股、港股、美股上市主体）→ **无论控股还是参股，一律停止下钻**，T 即链条终点：
- 表内标注【上市公司】并注明上市地与证券代码；
- 已采集数据中，上市公司下属的**非上市**子公司不再展示（链上标注"以下属上市公司体内，规则5抑制"）；上市公司下属的**上市公司**（如上市主体持股另一上市主体）仍保留行并同样标注【上市公司】；
- 上市公司的自身对外投资**不在本 skill 展开**；如需分析，另行建"上市公司对外投资"专门 skill。

**规则6·公司制基金即止**：T 为**公司制基金**——股份公司/有限公司形式的基金主体（名称含"投资基金/基金管理/产业基金"字样、经营范围主营股权投资，如国家集成电路产业投资基金二期股份有限公司）→ 视同备案基金：**即止不穿透对外投资**，标注【公司制基金·即止】+基金管理人；其对外投资组合不披露。注意公司制基金走工商登记、可能无"私募基金"标签属正常，判据=名称+组织形式+经营范围，与规则3的标签口径并行。公司制基金入表9-X-D（若为间接持有）。

**三类终止主体细则（2026-10-17 v3.13，用户指令）**：对外投资链条上的停止对象归并为三类，共性要求（停止下钻、单元格短标签、说明一律入"表注："、比例逐字引用、体内抑制）按§2/§4既有纪律执行，此处只列各类专属规则：

1. **上市公司**（规则5）：
   - 认定：沪深北A股/港股/美股上市主体；表内标【上市公司·代码·上市地】；
   - 体系内上市公司控股的投资/管理/咨询字样主体，按§6.8例外1抑制名单改判参股尽头并括注"上市公司体内抑制"；
   - 其自身对外投资不在本 skill 展开；如需分析，另建"上市公司对外投资"专门 skill。
2. **备案基金产品（有限合伙或有限责任公司形式）**（规则3+规则6并轨）：
   - 认定——合伙制：MCP企业标识含"私募基金"标签=已备案、无标签=未备案；公司制（有限公司/股份公司形式基金）：名称含"投资基金/基金管理/产业基金"字样+经营范围主营股权投资判定，**无"私募基金"标签属正常**，判据=名称+组织形式+经营范围；严格核查一律以基金业协会公示为准（https://gs.amac.org.cn/amac-infodisc/res/pof/fund/index.html）。
   - 合伙制标【备案基金·即止】、公司制标【公司制基金·即止】，**均不披露对外投资组合**；
   - 双提取按规则4：执行事务合伙人（legal_person_name+legal_person_type，股东名单复核）+基金管理人（fund_manager_name+登记编号）+备案日期+运作状态；管理人≠执行事务合伙人时两个主体都列；
   - 协会官网核验到的备案号（S开头）入表注。
3. **私募基金管理人（登记）**（本次新增第三类）：
   - 认定：主体已完成私募基金管理人登记（MCP企业标识含"私募基金管理人"标签，或基金工具返回其为管理人），以登记编号（P开头）为准；
   - 即止：管理人主体本身停止下钻——**此处的"管理人"明确指在基金业协会登记的私募基金管理人**；其对外投资即其在管基金及跟投/SPV，穿透无增量信息且易越界；标注【私募基金管理人·登记编号·在管基金N只】，在管基金名录以协会公示为准（范例：杭州国舜股权投资有限公司 P1070771）；
   - 管理人与其发起基金的关系：管理人为GP的基金仍按第2类备案基金单独成表（B表），管理人处只标角色、不重复穿透；
   - **无登记编号不得标注**：仅有"投资管理/股权投资"字样的普通公司≠私募基金管理人（范例：杭州高科技创业投资管理有限公司等无牌照GP为普通主体，按控股/参股+例外1正常判定，不享受本类即止）。

**三类终止主体的附件机制（2026-10-17用户定，v3.14）**：上市公司、备案基金产品、私募基金管理人三类主体在全景核查中即止，但三者各有特点、对外投资内容通常较多，**值得专门成文**——分别由三个专门skill详细分析（10-上市公司对外投资分析 / 11-备案基金产品对外投资分析 / 12-私募基金管理人对外投资分析），产出**作为附件挂进央国企对外投资报告**（附件N，主报告表内只留【终止主体·详见附件N】指引，不重复展开）。触发条件：全景核查中命中三类主体即应启动对应专门skill；若某次核查三类主体数量少（如仅1-2户）且内容单薄，经用户确认后可不入附件、仅在主报告表注简列。

**规则冲突处理（2026-10-10用户定）**：
- 原有规则与本规则矛盾、或原有规则不存在而本规则新增 → **以本规则为准**；
- 本规则未提及、原有规则已说明 → **按原有规则执行**。

**边界**：本 skill 穿透到"对外出资全景"为止——被投公司自身的经营/财务不在本 skill 展开（属03/16/17）；上市公司按规则5即止标注；从本 skill 提取的链条是发现多路径持股（如西湖电子集团→华数数字电视传媒→华数传媒）的基础。

## 3. 执行顺序与工程纪律

1. **一级子公司名单先行**：从披露文件+01号skill架构图拿到一级子公司全量名单（募集书经常漏，以工商穿透为准补齐），一家一级子公司就是一个工作单元。
2. **逐家来做**：一家一级子公司从实体锚定→对外投资全量→按穿透规则递归→出该家分层表，**完整做完、自查无遗漏后，再开下一家**。禁止多家并发半成品。批量主体（如某家对外投资几十户）可用后台agent分批，但归并时必须以jsonl落盘数据为准，口头汇报不算数。
3. **层级台账**：每维护一个 `层级结构` 记录——L0=一级子公司本体，L1=其直接对外投资，L2=L1中控股/SPV主体的对外投资……每条边记：上层主体、下层主体、持股比例（单一+关联方合并口径）、认缴、入股日期（出资/首次认缴时间）、终止规则（规则1/2/3/5/6哪条止步）。
4. **未收录处理**：悟道库查无（多为新设/更名主体）→ 记录"悟道未收录"，标待核入缺口清单（按三列模板），**禁止编造替代**。
5. **完整性自查**：每家做完核对——对外投资条数与工商返回总数一致；每条边都有终止规则标注；有限合伙全有执行事务合伙人字段；备案基金全有管理人字段。

- **汇总表B·关键主体清单**：GP/执行事务合伙人/基金管理人/SPV平台去重清单（名称、角色、出现于哪些链条、注册资本），这是后续架构图与基金分析的直接底数。

**4.4 已退出对外投资（单独部分，与存续分开）**：
- 数据源：`get_historical_external_investments_by_id` 的退出记录（含 remove_date）+ 工商状态为注销/吊销的主体；
- 按类型分**三张表：已退出·公司 / 已退出·有限合伙 / 已退出·基金**（份额链带 remove_date 的已退出LP、注销/吊销LP均入此）；
- 字段：| 被投主体 | 原持股主体（一级子公司） | 持股比例% | 认缴（万元） | 入股时间（出资/首次认缴时间） | 退出时间 | 退出方式（转让/注销/吊销/吸收合并/上市减持·按工商记录） | 接手股东（名称+持股比例，查无标"无承接方"） | 退出性质（六种情形） |
- **退出性质判定（2026-10-11用户指令，六种情形）**：
  - ①**内部转让**——同时看工商变更的退出方与增加方：增加方为地方国企/体系内关联方且无其他增加方，同时标的公司或有限合伙注册资本未减少；
  - ②**大概率内部转让**——增加方中除关联方外还有少量其他投资者；
  - ③**转让第三方**——增加方即为其他投资者、无关联方承接；
  - ④**定向回购**——注册资本减少且无新增投资者（大概率定向回购退出）；
  - ⑤**注销退出**——标的工商状态为注销/吊销/解散（含简易注销、破产清算等终止情形）；
  - ⑥**上市减持退出**——标的上市后原股东二级市场减持或上市前股权上翻退出。
  - 辅助判据（内部划转验证）：接手方入股日期==退出方退出日期且认缴额一致 → 内部转让确证（承接方可能是曾用名主体，须以统一社会信用代码核实）；体系内承接（如杭州产业投资→杭州产投集团）属集团内部投资调整，加口径注记；
- 与存续表绝不混表；退出主体仍在投资链条历史事实中，不剔除不省略。

## 5. 状态核查与注销清零（2026-10-15 v3.7）

**5.1 状态核查纪律（存续/退出判定以工商状态为准，悟道"正常"不可盲信）**：
- 底稿定稿前对存续部分全部主体逐户核查工商状态（杭州资本498户核查发现115户非存续）；悟道对注销/吊销主体在部分接口返回 NONE 或状态字段缺失（实测7家 MISSING：宁波盈益/中电海康启物/光启/城市大脑创业投资/数字西湖/浙商嘉胜/中尊汇富），须交叉验证三来源：①悟道工商 comp_status/n_comp_status/cancel_date/revoke_date；②历史快照 jsonl（_extract2.jsonl 等）；③企查查核准日期=注销核准日期（企查查须先征得用户同意）。
- 标注格式：存续表行内【已注销·YYYY-MM-DD】/【已吊销·YYYY-MM-DD】/【已吊销·未注销·YYYY-MM-DD】；转退出表后退出性质=注销退出（YYYY-MM-DD）/吊销退出（YYYY-MM-DD）；注销日期缺失→"注销退出·工商字段缺失"。非存续主体的存续子公司投资随链抑制（删除+表注说明），全链路排除（A3/A4/D表/汇总表）。
- 统计口径对齐：退出表行数、章节标题（N笔）、汇总表存续户数三处必须同步更新（本次产业投资15→18笔、西湖电子7→48笔、科创C表12→10户、汇总未备案LP 7→6户/12→10户）。

**5.2 "对外投资显示0"根因——注销数据清零规律**：
- 悟道对已注销主体返回 total=0 空列表：主体注销后其对外投资列表被清零，"显示0其实还是有"即此现象——历史投资只能从历史工商记录获取。处置：主体转已退出表、标注注销状态、历史投资按可得数据补齐或标待核，**禁止把"0"当作"从未投资"**。
- 存续主体对外投资0同样须复核（真新设/真未投 vs 数据边界），按5.3三分类标签兜底并表注"数据边界待核"。

**5.3 "钻取无有效投资"三分类标签**（存续主体无有效对外投资记录时）：
- ①`存续·新设基金未投出（成立YYYY-MM-DD）`——成立未满1年的新设基金；
- ②`存续·悟道数据源未见对外投资（成立YYYY-MM-DD·数据边界待核）`——老LP/老平台悟道无记录，如实标注数据边界；
- ③`存续·营业期限YYYY-MM-DD届满未清算`——营业期限届满但未办理清算注销的僵尸主体（如君然2021-09-15届满）。
- 三分类口径说明必须写入相关各表表注（同一段表注可复用于多表）；计数校验时表注行与数据行须分开统计（表注行含标签文本，勿计入数据行）。

## 6. 工程守卫与返修纪律（2026-10-16 v3.8，杭金投返修沉淀）

**6.1 多波次钻取 schema 归一化层（防静默丢数）**：
- 不同波次采集脚本落盘 schema 不一致（如 w5 全量 `{lp_id,lp_name,total,invs:[{i_id,i_name,pct,cap}]}` vs 钻取 `{comp_id,name,cur:[{t_id,t_name,p,cap,inc,rm}]}`），渲染层只认统一口径，错配即静默丢弃。铁律：**渲染脚本开头设归一化层**，把所有中间文件映射到统一字段后再查表（如 `r['invs'] = [{i_id,t_name→i_name,p→pct,cap} for n in r['cur']]`），并注释声明防回归。
- rulecheck 守卫：逐条读钻取文件，凡 `cur` 非空的 LP，其 C 表行必须含"N笔"且不得含"钻取0投"——逐 LP 断言，不允许抽样。

**6.2 先判后钻（停止主体数据不得入 A3）**：
- 对排队钻取的下层主体，**先用停止规则过滤再发起钻取**：规则1参股即止/规则5上市公司即止/规则3已备案基金即止命中的主体，其已采集的对外投资数据**不入 A3 追加续钻表**（计 suppressed 行数入 manifest）。
- A2 处理列对停止主体只写"规则X·即止"，**禁止写"备查见A3表"**（会误导读者以为钻取结果已渲染）。
- rulecheck 守卫：manifest 记录 `stop_names`，扫描 A3 全部链条行，链条末位主体 ∈ stop_names 即报错（用户已裁定备查保留的链条除外，须显式豁免名单）。

**6.3 A2/A3 按 L1 控股主体分节（分子公司一张表）**：
- 续钻层表**按每个 L1 控股主体（一级子公司/本部直接）分节**，节内"二级续钻层表"+"追加续钻层表"各一张（参考杭州资本格式），禁止把所有子公司混排进一张大表。
- rulecheck 守卫：分节数 ≥ 实际 L1 控股主体数（杭金投实测 ≥15 节），且 A3 数据行总数 = manifest['a3_rows']。

**6.4 年报定存续核验纪律（存续/注销冲突的终裁）**：
- 用户记忆或旧快照称"已注销"，但悟道工商显示存续时，**以工商年报为决定性证据**：注销主体不可能公示年报——能查到当年年报（含从业人数、对外投资有无）即铁证存续。
- 年报"对外投资=否"连续三年 + 历史出资已退 → 真实状态为**存续空壳化**（非注销）：C 表穿透列标"0笔（存续·空壳化·见表注）"，历史投资入退出表，表注写明年报公示日期与依据（范例：杭州盛翰，2025年报2026-03-13公示·开业，2023-2025连续三年对外投资=否）。

**6.5 A表全口径列示与A2组头不自引用（2026-10-16 v3.8，杭实返修沉淀）**：
- **A表=全部L1公司行（参股+控股续钻），与杭州资本格式对齐**：规则2/例外1判为续钻的L1公司必须在A表有一行，处理列标"规则2·续钻"；**禁止只出现于A2组头而A表缺席**（杭实返修前缺陷：A表仅5户参股行，14户控股行丢失）。
- **A2组头不渲染为数据行**：判定层给组头行 note 统一前缀"组头"（L3/L4用"L3组头"/"L4组头"），渲染层跳过 note.startswith('组头') 的行只取其分组名；**禁止出现"组内唯一数据行=组头主体自身"的自引用**（杭实返修前183/203组自引用）。
- **下层无有效投资→回A表括注**：续钻主体钻取后（噪音剔除后）无有效行的，不设A2组，A表行处理列括注"（下层无有效投资）"；组内仅有cc=2删除记录（历史退出）的，组caption标"（无存续投资，历史退出见本节HIST表）"。

**6.6 深层穿透与多边缘主体守卫（2026-10-16 v3.9，杭州城投返修沉淀）**：
- **层级图 L2SET 必须从各波次文件分别构建（防深层塌缩）**：DRILL 全量键 ≠ L2 集。若 `L2SET = set(DRILL.keys())`（把 c/d/e/f/g 全部钻取文件键混为 L2），则 LVL 深层条件 `xc not in L2SET` 永假，L3/L4/L5 塌缩为 0、全部错层渲染为 A2（本次假象：L2组 395、深层 0；修复后 L2 147 / L3 203 / L4 36）。铁律：decide 加载段即按波次分层建 L2SET（仅 c 批=L2 候选），深层键只进 DRILL 不进 L2SET。

- **多边缘主体合法（检查按边不按主体）**：同一主体可在不同链上身份不同（范例：杭州湖塍置业 72.5% 控股续钻=组头 + 27.5% 参股尽头），属合法客观事实。rulecheck 的 a3_terminal∩stop_names 守卫必须豁免"自身为任一组头"的主体名。
- **rulecheck EXIT 名提取复位口径**：in_exit 标志须在**任意新标题行**（`### ` 或 `## `）复位——只认 `### ` 会把 HIST 表行吞入 EXIT 名单（同名 HIST+存续 误报 33 条）；只认 `## ` 会把末尾汇总表B（关键主体清单）吞入（一级子公司/续钻主体误报 54 条）。
- **噪音名检查跳过 EXIT/HIST 节**：同名异主体合法共存（范例：噪音股东名"杭州市路桥集团股份有限公司"与本部 HIST 旧名影子记录同姓不同体），噪音扫描仅限存续表节。
