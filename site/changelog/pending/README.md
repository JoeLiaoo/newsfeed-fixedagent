# 员工端更新日志待发布条目

每个员工可见的变更集写一个小写英文短名的 `.json` 文件，例如 `expert-task-list.json`。字段只写 `kind`（更新／优化／公告／下线）、`title`、非空字符串数组 `body`；确有需要时加 `"urgent": true`。不要写日期、时间或供应商品牌；发布步骤会统一填入北京时间。文案只描述这次发布实际交付的员工能力，不预告未发布工作，不把尚待验证的功能写成已验收。

功能 PR 提交待发布文件。发布负责人在将要构建的 Git tip 上运行 `npm run changelog:apply`，检查并提交更新后的 `site/changelog.json` 与删除的待发布文件，再从该提交构建镜像。没有待发布文件时命令可重复运行。
