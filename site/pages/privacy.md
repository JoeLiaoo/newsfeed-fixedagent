# 隐私说明

本平台供公司员工使用。账号和关注赛道用于登录、账号审核与个人化资讯展示；仅授权管理员可审核账号。部署前应补充实际运营主体、联系人和内部数据保留期限。

| 项 | 值 |
|---|---|
| 版本 | 1.0 |
| 生效日期 | 2026-10-21 |
| 运营主体 | 中信私募 |
| 联系方式 | 请联系平台管理员 |

## 1. 账号与兴趣设置

注册时需提供用户名、真实姓名和密码。密码以加盐哈希形式保存，不以明文保存。管理员审核账号后可登录。平台保存账号状态、角色、登录会话的哈希值以及用户主动选择的关注赛道，用于账号管理和个人日报；用户的关注赛道仅供本人和有账号管理权限的管理员使用。

## 2. 浏览器本地数据

收藏、已读记录、深浅色设置、最近搜索和反馈草稿可能保存在当前浏览器。本地数据不会自动在设备间同步；清除浏览器数据后会消失。

## 3. 信源提交与资讯

员工提交的 RSS、网站列表页或 sitemap 作为全员共享信源运行。平台只采集公开可访问的文章地址和内容，不采集需要登录或付费的内容。公开资讯摘要按用户关注赛道筛选；原文版权归各来源所有。

## 4. 反馈和访问日志

反馈页提交的内容、选填的邮箱及所在页面会保存在服务器用于处理反馈。服务器、反向代理或 CDN 可能按实际配置记录网络访问日志；具体范围和保留期限由部署方管理。

## 5. 账号处理与联系我们

需要更正或停用账号，请联系平台管理员。第三方原文链接会打开对应来源网站，并适用该网站的隐私政策。
