页首说明：

> 平台供公司员工阅读公开信源并查看个人化资讯。员工账号需经管理员审核；原文版权归各来源所有。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

## 3. 使用本站的数据

平台资讯限公司内部阅读和分析，不应超出来源授权范围进行公开转载或批量再分发。请以原文来源的授权条件为准。

## 4. 接口与频率

现有匿名 RSS、公开 API 和 MCP 只返回公开资讯。个人日报、账号管理和关注设置需要员工登录；不要尝试访问他人账号或绕过访问控制。

## 5. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。
